# Dino Game - Интеллектуальная игра с тремя типами препятствий

## Описание
Расширенная версия классической игры Chrome Dino с добавлением третьего типа препятствия - **Низкой перекладины (Low Bar)**.

## Реализованные функции

### Задание 1: Расширение функциональности игры

#### Три типа препятствий:
1. **Кактус (Cactus)** - зелёный, растёт на земле, требует прыжка
2. **Птица (Bird)** - красная, летит на разной высоте, требует прыжка или приседания
3. **Низкая перекладина (Bar)** - серая, расположена на уровне груди динозавра, требует приседания

#### Механика поведения динозавра:
- **Прыжок** (SPACE) - одинарный или двойной прыжок
- **Приседание/скольжение** (DOWN/S) - уменьшение высоты для прохождения под перекладиной и птицами
- **Визуальная индикация**: 
  - Серый цвет - обычное состояние
  - Синий цвет - режим скольжения
  - Голубой цвет - двойной прыжок

#### Генерация препятствий:
- Случайная генерация всех трёх типов препятствий
- Вероятности появления: кактус (50%), птица (30%), перекладина (20%)
- Постепенное увеличение скорости игры

### Задание 2: Система сенсора и нейронная сеть

#### Сенсорная система:
- Обнаружение препятствий в радиусе 300 пикселей
- Определение расстояния до каждого типа препятствия
- Определение высоты препятствий
- Передача информации о состоянии динозавра

#### Нейронная сеть:
- Архитектура: 8 входов → 16 скрытых нейронов → 3 выхода
- Входы: данные сенсора (расстояния, высоты, скорость, состояние)
- Выходы: 3 действия (ничего, прыжок, приседание)
- Функции активации: ReLU (скрытый слой), Softmax (выходной слой)

#### Обучение:
- Генерация обучающих данных (2000 примеров)
- Алгоритм обратного распространения ошибки
- Сохранение/загрузка модели в файл

## Управление

### Клавиши управления:
| Клавиша | Действие |
|---------|----------|
| SPACE | Прыжок / Рестарт после проигрыша |
| DOWN / S | Приседание (скольжение) |
| A | Включить/выключить автоматический режим |
| T | Обучить нейронную сеть |
| L | Загрузить обученную модель |
| R | Тестировать модель (10 игр) |

## Инструкция по использованию

### Режим ручного управления:
1. Запустите игру
2. Используйте SPACE для прыжка через кактусы
3. Используйте DOWN или S для приседания под перекладинами
4. Избегайте столкновений с препятствиями

### Режим автоматического прохождения (AI):
1. Нажмите **T** для обучения нейронной сети (подождите завершения обучения)
2. После обучения модель автоматически сохранится в `dino_nn_model.pkl`
3. Нажмите **A** для включения автоматического режима
4. Наблюдайте, как ИИ проходит игру самостоятельно
5. Нажмите **L** для загрузки сохранённой модели
6. Нажмите **R** для тестирования модели (серия из 10 игр)

## Классы и компоненты

### Основные классы:
- **Dino** - класс динозавра с физикой прыжков и скольжения
- **Obstacle** - базовый класс препятствий (кактус, птица, перекладина)
- **Sensor** - сенсорная система для обнаружения препятствий
- **NeuralNetwork** - нейронная сеть для принятия решений
- **Trainer** - алгоритм обучения нейронной сети
- **Game** - основной игровой цикл и логика
