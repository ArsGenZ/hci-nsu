# Dino Game - Интеллектуальная игра с двумя типами препятствий

## Описание
Версия классической игры Chrome Dino с двумя типами препятствий: **Кактус** и **Птица**.

## Реализованные функции

### Три типа препятствий (ОРИГИНАЛЬНАЯ ВЕРСИЯ):
1. **Кактус (Cactus)** - зелёный, растёт на земле, требует прыжка
2. **Птица (Bird)** - красная, летит на разной высоте, требует прыжка или приседания
3. ~~Низкая перекладина (Bar)~~ - УДАЛЕНО по требованию

### Текущая версия (2 типа препятствий):
1. **Кактус (Cactus)** - зелёный прямоугольник на земле, требует прыжка
2. **Птица (Bird)** - красный прямоугольник на разной высоте:
   - Низко (требует прыжка)
   - Высоко (можно пробежать)

#### Механика поведения динозавра:
- **Прыжок** (SPACE) - **только одинарный прыжок** (двойной прыжок удалён)
- **Визуальная индикация**: 
  - Тёмно-серый цвет - обычное состояние (на земле)
  - Синий цвет - во время прыжка

#### Генерация препятствий:
- Случайная генерация двух типов препятствий
- Вероятности появления: кактус (60%), птица (40%)
- Постепенное увеличение скорости игры

### Система сенсора и нейронная сеть:

#### Сенсорная система:
- Обнаружение препятствий в радиусе 300 пикселей
- Определение расстояния до кактуса и птицы
- Определение высоты препятствий
- Передача информации о состоянии динозавра (в прыжке или нет)

#### Нейронная сеть:
- Архитектура: **6 входов → 12 скрытых нейронов → 2 выхода**
- Входы: данные сенсора (расстояние до кактуса, высота кактуса, расстояние до птицы, высота птицы, скорость динозавра, состояние прыжка)
- Выходы: 2 действия (ничего не делать, прыжок)
- Функции активации: ReLU (скрытый слой), Softmax (выходной слой)

#### Обучение:
- Генерация обучающих данных (2000 примеров)
- Алгоритм обратного распространения ошибки
- Сохранение/загрузка модели в файл

## Управление

### Клавиши управления:
| Клавиша | Действие |
|---------|----------|
| SPACE | Прыжок / Рестарт после проигрыша |
| A | Включить/выключить автоматический режим |
| T | Обучить нейронную сеть |
| L | Загрузить обученную модель |
| R | Тестировать модель (10 игр) |

## Инструкция по использованию

### Режим ручного управления:
1. Запустите игру
2. Используйте SPACE для прыжка через кактусы и низких птиц
3. Если птица летит высоко - просто бегите под ней
4. Избегайте столкновений с препятствиями

### Режим автоматического прохождения (AI):
1. Нажмите **T** для обучения нейронной сети (подождите завершения обучения)
2. После обучения модель автоматически сохранится в `dino_nn_model.pkl`
3. Нажмите **A** для включения автоматического режима
4. Наблюдайте, как ИИ проходит игру самостоятельно
5. Нажмите **L** для загрузки сохранённой модели
6. Нажмите **R** для тестирования модели (серия из 10 игр)

## Классы и компоненты

### Основные классы:
- **Dino** - класс динозавра с физикой прыжков (только одинарный прыжок)
- **Obstacle** - класс препятствий (кактус, птица) - все прямоугольники
- **Sensor** - сенсорная система для обнаружения препятствий
- **NeuralNetwork** - нейронная сеть для принятия решений (6→12→2)
- **Trainer** - алгоритм обучения нейронной сети
- **Game** - основной игровой цикл и логика
