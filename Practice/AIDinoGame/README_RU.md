# Dino Game с PyTorch AI (Расширенная версия)

## Описание
Интеллектуальная игра "Динозавр" (аналог Chrome Dino) с расширенным функционалом и поддержкой нейронной сети на PyTorch.

## Новые возможности (Задание 1)

### Третий тип препятствия: Пропасть (Gap)
- **Описание**: Разрыв в земле, требующий выполнения двойного прыжка
- **Механика**: При приближении к пропасти динозавр должен выполнить обычный прыжок, а затем двойной прыжок для преодоления разрыва
- **Визуализация**: Коричневый прямоугольник под землей, разрыв в линии земли

### Двойной прыжок
- **Управление**: Клавиша `D` (в ручном режиме)
- **Механика**: Доступен только когда динозавр находится в воздухе над пропастью
- **Индикация**: Цвет динозавра меняется на голубой `(0, 200, 255)` при выполнении двойного прыжка

### Три типа препятствий:
1. **Кактус** (зеленый) - требует обычного прыжка
2. **Птица** (красная) - требует приседания
3. **Пропасть** (коричневая) - требует двойного прыжка

## Нейронная сеть (Задание 2)

### Архитектура
```python
class DinoNet(nn.Module):
    Input: 8 признаков
    Hidden: 20 нейронов (ReLU)
    Output: 4 класса действий
```

### Входные данные сенсора (8 признаков):
1. `dist_cactus` - расстояние до кактуса (нормализованное)
2. `h_diff_cactus` - разница высот с кактусом
3. `dist_bird` - расстояние до птицы (нормализованное)
4. `h_diff_bird` - разница высот с птицей
5. `dist_gap` - расстояние до пропасти (нормализованное)
6. `dy` - вертикальная скорость динозавра
7. `is_jumping` - флаг прыжка (0/1)
8. `can_double_jump` - доступен ли двойной прыжок (0/1)

### Выходные действия (4 класса):
- `0` - Ничего не делать (бежать)
- `1` - Прыжок
- `2` - Приседание
- `3` - Двойной прыжок

## Управление

| Клавиша | Действие |
|---------|----------|
| `SPACE` / `W` | Прыжок |
| `S` | Приседание (удерживать) |
| `D` | Двойной прыжок (когда доступен) |
| `A` | Включить/выключить автопилот (AI) |
| `T` | Начать/остановить обучение |
| `R` | Загрузить модель и запустить тестирование |
| `L` | Загрузить сохраненную модель |

## Особенности реализации

### Обработка пропасти
- Динозавр "падает" когда находится над пропастью
- Активируется возможность двойного прыжка
- Земля рисуется с визуальным разрывом

### Сенсорная система
- Сканирует пространство перед динозавром на 250 пикселей
- Обнаруживает все три типа препятствий
- Передает нормализованные данные в нейронную сеть

### Обучение с учителем
- Используется логика "учителя" для генерации правильных действий
- Периодическое обновление весов нейронной сети каждые 50 кадров
- Сохранение/загрузка модели через torch.save/load
